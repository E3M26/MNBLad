# MNBLad

ESP32-S3 tabanlı, tarayıcıdan **ladder** ile programlanan PLC'nin web paneli.

**Panel:** https://e3m26.github.io/MNBLad/ · **Kullanma kılavuzu:** https://e3m26.github.io/MNBLad/kilavuz.html

- Chrome veya Edge (bilgisayar) gerekir; kart USB ile bağlanır (Web Serial).
- **İnternetsiz kullanım (Windows):** [MNBLad_Panel.zip](https://e3m26.github.io/MNBLad/indir/MNBLad_Panel.zip) indirip çıkarın, `MNBLad Panel.bat` çift tıklayın. Kurulum gerekmez.
- Kart olmadan denemek için: **Bağlan → ▶ Simülasyon**.
- Firmware güncelleme panelin **Ayarlar** sekmesinden yapılır (`firmware/` klasöründeki paket).

Bu repo yayın kopyasıdır; kaynak ve geliştirme notları ayrı tutulur.
